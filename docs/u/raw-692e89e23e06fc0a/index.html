This item is a Cabinet Order (Reiwa 8 Cabinet Order No. 134) that amends an existing Cabinet Order (Heisei 19 Cabinet Order No. 325) concerning the calculation of grants for the early elderly and national treasury contributions for later-stage elderly medical care.
