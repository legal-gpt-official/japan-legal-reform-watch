要約

環境省設置法の一部を改正する法律の施行に伴い、環境省関係省令を整備する省令（令和八年環境省令第十九号）が公布されたことが更新一覧に掲載されています。対象法令は、特定有害廃棄物等の輸出入等の規制に関する法律に基づき特定有害廃棄物等の範囲等を定める省令（平成三十年環境省令第十二号）とされています。原文の記載では、公布日は2026年6月30日、施行日は2026年7月1日と示されています。

事業への影響

特定有害廃棄物等の輸出入に関わる事業においては、省令整備に伴う規定の変更が実務に影響する可能性があります。また、環境省設置法改正に関連する所管や手続の整理が関係する事業に影響を及ぼすことも考えられます。
