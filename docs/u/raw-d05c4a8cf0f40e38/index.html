Summary

This is a public comment invitation regarding a draft partial amendment to standards set by the Prime Minister and the Minister of Health, Labour and Welfare concerning the disability welfare system. The draft covers details of functional requirement standards, implementation categories, conformity reference dates, form (document) requirement standards, and other matters related to document output.
