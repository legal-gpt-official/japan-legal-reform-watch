Summary

The Digital Agency published an advance notice on 2026-11-13 announcing planned CSV format changes for town and aza subdivision data in the Address Base Registry, alongside a system renewal in late January 2027. Residential-address, residential-block and land-parcel-number data may also change. Temporary access to the existing format for existing users is under consideration, but data added or updated after the renewal is planned to be available only in the new format. The notice states that ABR Geocoder users will need a new version; changes to its API definitions may also require adjustments to systems using it. Detailed changes, sample CSV data and the system renewal date are scheduled to be announced around December 2026.

Business Impact

Users operating systems that import the registry's town and aza subdivision data or related datasets may need software or configuration changes. Systems using ABR Geocoder could also need integration updates and testing because its internal processing and API definitions will change.

Recommended Action

Users could review CSV import dependencies and ABR Geocoder integrations against the sample data and API changes scheduled for release around December 2026, and consider testing ahead of the planned late-January 2027 transition. Any reliance on continued access to the existing format could be reviewed, since that arrangement is only under consideration and would exclude later additions and updates.
