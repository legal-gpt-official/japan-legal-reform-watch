要約

文部科学省は、大学の設置等の認可の申請及び届出に係る手続等に関する規則（平成十八年文部科学省令第十二号）を改正する省令（令和八年文部科学省令第二十九号）を公布しました。原文によれば、大学設置基準もあわせて改正するもので、公布日および施行日はいずれも2026年9月4日と記載されています。更新一覧への掲載日は2026年9月25日です。

事業への影響

大学の設置基準や設置認可の申請・届出手続に関わる教育機関等の実務に影響が及ぶ可能性があります。改正内容の詳細によっては、申請・届出の準備方法の見直しが必要となることも考えられます。
